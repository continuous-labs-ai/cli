## Continuous CLI v0.1.0

The first release of the Continuous CLI provides commands for the Continuous Simulation API.

### Included

- Commands for Simulators, Simulations, and Worlds.
- JSON, YAML, table, and terminal output options.
- API key authentication through `CONTINUOUS_API_KEY_AUTH`.
- Linux, macOS, and Windows downloads for amd64 and arm64.

### Install

Download the archive for your system and `checksums.txt` from the release assets below.
Verify the SHA-256 checksum before extracting the archive. Checksums are not signed.

See the [installation guide](https://github.com/continuous-labs-ai/cli#install-an-approved-release) for setup and API authentication.
