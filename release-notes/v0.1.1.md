## Continuous CLI v0.1.1

This release improves installation and adds Homebrew distribution. API commands and authentication behavior remain unchanged.

### Installation improvements

- Generated installers for Linux, macOS, and Windows verify SHA-256 checksums before installation and retain licenses and notices.
- Release archives include the project license, dependency notices, and Go license and patent grant.
- The Homebrew formula installs the CLI and Bash, Zsh, and Fish completions on macOS and Linux.
- The installation guide explains API key login, credential storage, and JSON output for automation.

### Install

After the Homebrew publication workflow completes, install the CLI with:

```bash
brew install continuous-labs-ai/tap/continuous
continuous version
```

Alternatively, use the [installation guide](https://github.com/continuous-labs-ai/cli#install-an-approved-release) to install this version with an installer or archive.

Downloads support Linux, macOS, and Windows on amd64 and arm64. Checksums are unsigned and do not prove publisher identity.
